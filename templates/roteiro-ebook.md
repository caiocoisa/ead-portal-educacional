# Template de roteiro: ebook interativo

> Esqueleto de `pesquisa/engenharia-reversa/ebook.md`. Copie para
> `conteudo/ebook/` e preencha. Atende ao requisito R1: capa, sumário e
> capítulos em ordem lógica, design profissional, interatividade e
> linguagem clara. **Evidência desta mídia é a mais fraca**: o modelo de
> capítulo abaixo tem baixa confiança e deve ser revisto com ebooks reais.

## 1. Ficha

| Campo | Preenchimento |
|---|---|
| Título e subtítulo | |
| **Promessa** (o que o leitor consegue fazer ao fim) | |
| Público | _educadores, licenciandos, designers instrucionais, sem experiência com IA_ |
| Total de capítulos | |
| Extensão estimada | |
| Plataforma de publicação | _FlipHTML5 ou Genially (Task 58)_ |

## 2. Capa

Título, subtítulo, promessa em uma linha, autoria. **Arte sem texto na
imagem;** o texto vai em HTML ou na diagramação.

## 3. Sumário

Lista clicável: cada item leva ao capítulo. Incluir número de página.

## 4. Capítulos

Repita o bloco para cada capítulo.

| Parte | Conteúdo | Limite |
|---|---|---|
| **Abertura** | Objetivo do capítulo ou pergunta-foco | 2 a 3 frases |
| **Conceito** | A ideia central, com termo técnico definido no primeiro uso | 1 página |
| **Exemplo ou caso** | Cenário novo (não o de uma questão) | 1 página |
| **Prática** | Atividade ou modelo de comando para o leitor usar | 1 página |
| **Elemento interativo** | Um por capítulo: sumário clicável, cartão que revela, galeria com detalhe, autoverificação | 1 |
| **Checklist e síntese** | Ações para o leitor e resumo | meia página |

## 5. Glossário e referências

Termos em linguagem simples; referências citadas.

## 6. Linguagem clara (obrigatório)

- [ ] Frases curtas.
- [ ] Termo técnico definido no primeiro uso.
- [ ] Glossário no fim.
- [ ] Revisão por 2 ou 3 educadores do perfil-alvo.

## 7. Duas faces (decisão do plano)

- **Versão interativa:** publicada na plataforma escolhida.
- **Versão acessível:** o HTML do leitor no portal, com o mesmo conteúdo. O PDF não é oferecido para download; serve só de fonte para a plataforma.

## 8. Checklist de qualidade

- [ ] Capa, sumário navegável e capítulos em ordem lógica.
- [ ] Todo capítulo segue a mesma estrutura.
- [ ] Pelo menos um elemento interativo por capítulo.
- [ ] Nenhum capítulo revela a resposta de uma questão.
- [ ] Vocabulário igual ao do vídeo e do glossário.
